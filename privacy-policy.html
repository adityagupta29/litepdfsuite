Privacy Policy

Last updated: August 2026

The short version: Lite PDF Suite never sees your files. Every tool runs as JavaScript inside your own browser, so there is nothing for us to collect, store, or lose, because your document never leaves your device in the first place.

How the tools actually work

When you open a PDF in any tool on this site, the file is read directly by your browser using client-side libraries such as pdf.js and pdf-lib. Merging, splitting, compressing, converting, watermarking, e-signing, and password protection all happen locally on your own computer or phone. At no point is the file sent to a server we control, because there is no such server in the processing path at all.

You can verify this yourself: open your browser's network tab while using any tool and watch that your document is never part of an outgoing request.

What we don't collect

  • We don't ask you to create an account, so we have no name, email, or password of yours to store.
  • We don't see the content of any PDF, image, or document you process, and it's never sent to us or to Google Analytics.
  • We don't run advertising trackers, and we don't sell or share data with data brokers.

Analytics

This site uses Google Analytics to understand overall traffic, such as which tools are used most and roughly how many people visit, so we know what's worth improving. Google Analytics uses cookies and collects information like your approximate location (city/country level, from IP address), device and browser type, and which pages you visit. It does not have access to, and never receives, the content of any file you process with a tool.

You can opt out of Google Analytics tracking using a browser extension such as the Google Analytics Opt-out Browser Add-on, or by blocking third-party cookies and scripts in your browser's privacy settings. See Google's Privacy Policy for how Google itself handles this data.

What is stored, and where

A small amount of information is saved directly in your browser's own local storage, not on any server:

  • Theme preference (light or dark mode), so the site remembers your choice on your next visit.
  • In-progress work on a couple of tools, such as page arrangement in Merge & Rearrange, so a page refresh doesn't lose your layout. The actual PDF file content is not part of this, only arrangement metadata, which is why you're asked to re-upload files after a browser restart.

All of this lives only on your own device. It is never transmitted anywhere, and you can clear it at any time through your browser's site settings.

Lite PDF Suite is a static website with no backend server of its own. Everything above describes the site's own code; it doesn't change what a browser, operating system, or network generally does on any website you visit.

Hosting and third-party requests

This site is hosted as a static site. Simply loading any page means your browser makes standard web requests to the hosting provider, which may log basic technical information (such as IP address and browser type) the way any web server does. We don't have access to build a profile from these logs, and they exist purely as part of normal web hosting infrastructure.

Pages also load a small number of third-party resources needed for the design to work: Google Fonts (for typefaces) and Font Awesome via a CDN (for icons). Loading these means your browser makes a request to those providers, which may see basic request metadata like your IP address, the same as loading a font or icon from any other website. None of these are used to track you across the web by us, and no PDF content is ever included in these requests.

Children's privacy

This site is not directed at children and does not knowingly collect personal information from anyone, regardless of age, since it does not collect personal information at all.

Changes to this policy

If this policy changes, the update will be posted on this page with a new "last updated" date. Continued use of the site after a change means you accept the revised policy.

Contact

Lite PDF Suite is an open-source project. Questions or concerns can be raised through GitHub Issues on the project's repository.
